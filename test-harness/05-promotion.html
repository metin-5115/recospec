05 — Click-target promotion

Clicking a presentational leaf (an icon path, a span) should record the nearest actionable ancestor — never the leaf. Form controls and bare text are never promoted.

Icon path inside a button → button → testid

Clicking the <path> promotes to the enclosing button.

Icon inside an anchor (no text) → a → href

A text-less icon link promotes to the anchor, which keys on its href.

Text span inside an anchor → a → role-name

Promotes to the anchor; an a[href] has the link role, so role + name wins.
