06 — Repeated card lists

The etstur case. A leaf with a dynamic value (price / date) inside a repeated card, with no unique class or test-id, must be scoped by a stable sibling label — never a score-0 positional XPath, and the dynamic value must never appear in the locator.

No test-id → container anchor by stable name → composed (filter hasText)

Cards share a class, prices/dates are dynamic. The engine should scope each row by its hotel name and target the leaf within.
