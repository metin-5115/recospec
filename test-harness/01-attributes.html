01 — Attribute strategies

Test-id family (highest priority) plus name / placeholder / alt / title.

Test-id family → testid

All six recognized attributes. data-testid, data-test-id and data-cy map to the testid strategy; the rest to test-attr.

Secondary test attributes → test-attr

data-test, data-qa, data-automation.

Form-control attributes

No id / label nearby, so each control falls to its own attribute.

Image alt & title → role-name / title

An alt becomes the image's accessible name (→ role-name); a control-less icon with no name falls back to title.
